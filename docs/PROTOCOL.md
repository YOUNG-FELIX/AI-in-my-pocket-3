# 协议实测

DJI Osmo Pocket 3 的四条通路全部实测过。这是结论和证据。

---

## 一、USB 接口布局

同一个相机，USB 描述符随模式变：

### 文件传输模式 `VID_2CA3&PID_0020`

| 接口 | 类 | 硬件 ID | 状态 |
|---|---|---|---|
| MI_00 | Net | `Class_e0&SubClass_01&Prot_03` (RNDIS) | ✅ |
| MI_02 | USB | `Class_08&SubClass_06&Prot_50` (Mass Storage) | ✅ |
| MI_03..MI_07 | — | **`Class_ff&SubClass_43&Prot_01`** | ❌ Error，无驱动 |

五个 BULK 是 DJI 私有 DUML 通道（`SubClass 0x43` 是 DUML 典型子类）。
实例 ID 形如 `USB\VID_2CA3&PID_0020&MI_0X\6&3958c552&1&000X`。

### 网络摄像头模式 `VID_2CA3&PID_0023`

| 接口 | 类 | 状态 |
|---|---|---|
| MI_00 | Camera (`OsmoPocket3`) | ✅ |
| MI_02 | MEDIA（USB 音频） | ✅ |

**只有 2 个 MI，BULK 接口不存在。** SD 卡也不挂载。

### 模式互斥

- UVC 开着时去连 Mimo 会超时
- 退出 UVC 后 Mimo 才恢复
- 「取消」= USB 完全不枚举

## 二、UVC / DirectShow

### 能用的控制

`IAMCameraControl` 接口，四个真控制：

| 参数 | 范围 | 默认 | 语义 |
|---|---|---|---|
| `PAN` | −35 .. 215 | 0 | 绝对角度，正数向右 |
| `TILT` | −90 .. 90 | 0 | 正数=镜头向下 |
| `ROLL` | −30 .. 30 | 0 | |
| `ZOOM` | 100 .. 400 | 100 | 100=1.0×，400=4.0× |

```python
PAN, TILT, ROLL, ZOOM = 0, 1, 2, 3
FLAG_MANUAL = 0x0002
cc.Set(PAN, 60, FLAG_MANUAL)     # HRESULT 0 = 调用成功，不代表真的动了
ok, val = cc.Get(PAN)            # 回读不可信，pan 轴尤其明显
```

### 不能用的控制（全部不暴露）

- `IAMVideoProcAmp`：接口**不支持**（`-2147467262`）
  ⇒ 亮度/对比度/色相/饱和度/锐度/伽马/白平衡/背光/增益 全部没有
- `IAMCameraControl` 的 `Exposure` / `Iris` / `Focus`：`GetRange` 报「找不到元素」
- UVC 厂商扩展单元（XU）：Pocket 4 有 Unit 6（GUID `41769EA2-04DE-E347-8B2B-F4341AFF003B`），
  **Pocket 3 这个固件没开**。四种寻址变体（`IKsPropertySet::Get` / `IKsControl::KsProperty` /
  `GET|TOPOLOGY` / `KSPROPSETID_VIDCAP_EXTENSION_UNIT` + inst）全部「属性集不存在」
- OpenCV `CAP_PROP_*` 23 项实测：只有 `PAN`/`TILT` 真生效，其余 16 项 `not implemented`

### 分辨率 / 帧率矩阵（实测）

| 请求 | 实际得到 | fps |
|---|---|---|
| 3840×2160 | 3840×2160 | 13 |
| 2720×1530 | 回落 1920×1080 | 32.8 |
| 2560×1440 | 回落 1920×1080 | 30.6 |
| **1920×1080** | **1920×1080** | **30.5** |
| 1280×720 | 1280×720 | 26.9 |
| 960×540 / 640×480 | 回落 1280×720 | ~33 |

fps 请求：60→29.8，50→30.1，30→30.3，25→25.1，24→24.2，15→24.3。
即 **60/50 都被压到 30，15 被抬到 24**。

像素格式：只有 **MJPG** 可靠。H.264 `set` 返回 False。YUY2/NV12 被接受但静默回落 MJPG。

竖屏 `720×1280` / `1080×1920` 是**独立 profile**（相机随机身姿态切换），不是旋转。

⚠️ **4K 前 4 帧解码不全**（只有左上角有内容，其余全黑，nonblack 仅 6–11%），第 5 帧起才 100%。

## 三、蓝牙（BLE）

**结论：能读不能写。**

| 项 | 结果 |
|---|---|
| 广播 | `OsmoPocket3-6789` / `88:29:85:CF:C1:44` / rssi −37 |
| 服务 | `0000fff0`（DJI DUML）、`0000180f`（电量）、`00001812`（HID） |
| 厂商数据 | `{2218 (0x08AA): 2000c0882985cfc144}`，`2000` = model id `0x0020` = Pocket 3 |
| 特征 | `FFF3` `FFF4` `FFF5`（与所有逆向文档一致） |

### 握手（照文档做，必须三步）

```
订阅 FFF4 + FFF5 的 CCCD
向 FFF4 特征值写 01 00 (with response)     ← 不是 CCCD
睡 200ms
```

### 能做的

| 功能 | 命令 | 结果 |
|---|---|---|
| 配对 | `07/45` | `0002`（需批准）→ 屏幕点「允许」→ `0001`（**持久**） |
| 设备信息 | `00/81` → `0x48` | |
| **注册** | `00/88` → `0x28` | 回 `00`，成功 |
| 心跳 | `00/88` sub `0x17` 每 1Hz | |
| **订阅参数** | `00/99` | ✅ 订阅 `cam_status`/`cam_storage` 等能收到推送 |
| 遥测 | — | `02/80`（相机状态）、`02/DC`（存储）、`04/05`（**云台四元数**）~15fps |

### 不能做的

| 功能 | 命令 | 结果 |
|---|---|---|
| **虚拟摇杆** | `04/01` | ❌ 4 个中继地址 × 2 方向 = **8 次全零位移**，遥测全程活 |
| **拍照** | `02/01` | ❌ `e0` |
| **录像** | `02/02` | ❌ `e0` |
| **切模式** | `02/E1` | ❌ `e0` |
| 相机模块 | `0x01` | ❌ 完全静默（接收方不存在） |
| 云台模块 | `0x03` | ❌ 完全静默 |

`cmd_type` 试过 `0x00`(PUSH) 和 `0x40`(REQUEST)，PUSH 全静默，REQUEST 只有 DM368 回 `e0`。
**Video 模式 + SD 卡插好 + 79 分钟可录，照样全拒。**

⇒ 蓝牙是**只读遥测 + 订阅**通道。

### 但遥测很值钱

`04/05` 是**真实云台姿态四元数**（49 字节 payload，offset 24 起 4 个 float32，模长恒为 1.000）：

```
quat (0.0569, 0.8591, -0.4992, 0.0979)  norm 1.000  pitch -13.00  yaw -60.32
```

实测 1:1 跟随：

| 指令 | yaw 变化 | 误差 |
|---|---|---|
| pan 0→60 | −50.29 → 9.65（Δ 59.94°） | 0.06° |
| pan 60→120 | 9.65 → 69.71（Δ 60.06°） | 0.06° |
| pan 120→0 | 69.72 → −50.11（Δ 119.83°） | 0.17° |

**关系式：`yaw = pan − 60.3°`**（机身朝向偏置）。

⇒ 这解决了「UVC 回读不可信」的技术债，可以做**真闭环**。

## 四、WiFi / DUML

蓝牙不给的拍摄命令，这条路完整存在：

```
53/10 → 0x1C        唤醒 WiFi AP
07/07 / 07/0E       读 SSID / 密码
→ 连相机热点
TCP 7001            bootstrap
UDP 9004            DUML 数据链
```

### DUML 帧格式

```
[0]     0x55            魔数
[1]     总长
[2]     0x04
[3]     CRC8
[4]     sender
[5]     receiver
[6:8]   seq : u16-LE
[8]     cmd_type
[9]     cmd_set
[10]    cmd_id
[11:-2] payload
[-2:]   CRC16 : u16-LE
```

### CRC（`duml.py` 已实现）

- **帧头 CRC8**：poly `0x8C`，init `0x77`，反射，xorout 0，覆盖 `bytes[0:3]`
- **帧尾 CRC16**：CRC-16/X.25，poly `0x8408` 反射，**种子 `0x3692` 必须作寄存器初值**

⚠️ 种子当寄存器初值 vs 当最后 xor，是完全不同的结果。**这是唯一卡住的点**，
之前所有「标准 CRC 参数」猜测都因此失败。参照实现：`o-gs/dji-firmware-tools` 的
`comm_dat2pcap.py`（`calc_pkt55_checksum` / `calc_pkt55_hdr_checksum`）。

自测：**8/8 参考帧校验通过，5/5 帧从字段重建后与原样本字节级一致**。

### 寻址

**`receiver = (id << 5) | type`**

| 值 | 含义 |
|---|---|
| `0x01` | Camera (type 1, id 0) |
| `0x03` | Gimbal (type 3, id 0) |
| `0x05` | Battery |
| `0x07` | WiFi / 配对 |
| `0x08` | DM368 (type 8, id 0) |
| `0x28` | DM368 id 1（**注册目标**） |
| `0x48` | DM368 id 2（**设备信息目标**） |
| `0xF0` | 会话端点 (type 0x10, id 7) |
| `0x1C` | 会话端点 (type 0x1C, id 0) |

### 常用命令

| 命令 | 说明 |
|---|---|
| `02/01` | 拍照，payload `[01]` |
| `02/02` | 录像 `[01]` 启动 / `[00]` 停止（**不是 toggle**） |
| `02/E1` | 拍摄模式：`0x00` SlowMo / `0x01` Video / `0x02` TimeLapse / `0x05` Photo / `0x0a` HyperLapse / `0x28` SuperNight / `0x0c` Panorama |
| `02/8E` | 参数 GET/SET：`GET=00 01 <pid:u16-LE>`、`SET=01 01 <pid:u16-LE> <len> <value>` |
| `02/A0` | 状态查询，`recording_time_s = u16-LE @6` |
| `04/01` | 虚拟摇杆，10 字节：`[pitch:u16-LE @0..1][yaw:u16-LE @4..5][00 80 22 00 @6..9]`，中立 1024，20Hz 发送 |
| `04/05` | 云台遥测（四元数） |
| `04/4C FE08` | 云台回中 |
| `04/4C FE09` | 自拍翻转 |
| `04/4C 00 00` | 云台锁定 |
| `00/6A` | 设时间 → 目标 `0x28` |
| `00/88` | 注册 / 心跳（sub `0x17`） |
| `00/99` | 订阅参数总线 |

### 应答码

| 码 | 含义 |
|---|---|
| `00` | 成功 |
| `d8` | 资源未就绪 |
| `d9` | 状态不对 |
| `df` | 参数错 |
| `e3` | 参数缺失 |
| `e0` | **不支持** |
| 无应答 | 接收方不存在 |

### ⚠️ 危险

**不要 sweep `02/E1` 的值空间去发现码值——会把相机冻死，必须断电重启。**

## 五、SD 卡（文件传输模式）

- exFAT 238 GB，盘符 `F:`
- `DCIM/`：`DJI_001_F01`、`DJI_002`、`PANORAMA`、`TIMELAPSE`，命名 `DJI_YYYYMMDDHHMMSS_NNNN_D_A01.{MP4,LRF,WAV,JPG,DNG}`
- `MISC/`：`AC004.db`、`PP-101.db`（SQLite），存拍摄元数据（时长、分辨率、光圈、ISO、缩略图偏移等）
- **`AC004` 是 Pocket 3 的机型代号**（EXIF `Model=AC004`，固件 `00.08.46.07`）
- `Android/` 是以前插过手机的残留，与相机无关

MP4 内嵌缩略图不在标准 `thmb` box，在 `©dji`/`udta` 区域。扫文件头 512KB 找 `FFD8FF…FFD9` 兜底最稳。
